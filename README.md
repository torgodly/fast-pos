# فاست بوس — نظام نقاط البيع

نظام نقاط بيع بسيط للمطعم والكافيه:

- شاشة رئيسية ببطاقتين (مطعم / كافيه)
- دخول الموظفين برمز PIN فقط (يعملون في أي فرع)
- النادل يفتح فواتير الطاولات ويضيف الأصناف
- الكاشير يحصّل الفواتير (نقدي / بطاقة) ويدعم البيع السريع
- لوحة إدارة واحدة للأصناف والطاولات والموظفين والتقارير

## التشغيل

```bash
bun install
bun run dev
```

افتح [http://localhost:3000](http://localhost:3000)

قاعدة البيانات SQLite تُنشأ تلقائياً في `data/pos.db` مع بيانات تجريبية.

## بيانات الدخول التجريبية

### الإدارة
- الرابط: `/admin/login`
- المستخدم: `admin`
- كلمة المرور: `admin123`

### الموظفون (يعملون في المطعم والكافيه)
- نادل: `1111`
- كاشير: `2222`

## التقنية

- Next.js (App Router)
- Tailwind CSS + DaisyUI
- SQLite + Drizzle ORM
- واجهة عربية بالكامل (RTL)
