# فاست بوس — نظام نقاط البيع

نظام نقاط بيع بسيط للمطعم والكافيه:

- شاشة رئيسية ببطاقتين (مطعم / كافيه)
- دخول الموظفين برمز PIN فقط (يعملون في أي فرع)
- السفرادجي يفتح فواتير الطاولات ويضيف الأصناف ويرسل للمطبخ
- الكاشير يحصّل الفواتير (نقدي / بطاقة) ويدعم البيع السريع
- طباعة صامتة عبر الشبكة لطابعات XPrinter (بدون حوار المتصفح)
- لوحة إدارة للأصناف والطاولات والموظفين والطابعات والتقارير

## التشغيل (محلي على الشبكة)

شغّل السيرفر على جهاز دائم داخل المطعم/الكافيه (mini PC) على نفس شبكة Wi‑Fi الخاصة بالأجهزة والطابعات:

```bash
bun install
bun run dev
# أو للإنتاج:
bun run build && bun start
```

`npm start` يستمع على `0.0.0.0:3000` ليتصل به الـ iPad عبر الشبكة.

**ملاحظة للشبكة المحلية (HTTP):** لا تفعّل `Secure` على الكوكيز. اترك `COOKIE_SECURE` غير معرّف.  
إذا استخدمت HTTPS لاحقاً: `set COOKIE_SECURE=true` قبل التشغيل.

افتح من الـ iPad: `http://IP-الجهاز:3000`  
قاعدة البيانات SQLite تُنشأ تلقائياً في `data/pos.db` مع بيانات تجريبية غنية:
أصناف، طابعات، محطات، طاولات، فواتير مفتوحة/مدفوعة/ملغاة لتجربة التقارير والإقفال.

لحذف القاعدة وإعادة التهيئة:

```bash
rm -f data/pos.db data/pos.db-shm data/pos.db-wal
bun run dev
```

## بيانات الدخول التجريبية

### الإدارة
- الرابط: `/admin/login`
- المستخدم: `admin`
- كلمة المرور: `admin123`

### الموظفون (يعملون في المطعم والكافيه)
- سفرادجي أحمد: `1111`
- كاشير سارة: `2222`
- سفرادجي يوسف: `3333`
- سفرادجي مريم: `4444`
- كاشير خالد: `5555`
- سفرادجي ليلى: `6666` (معطّل — للتجربة)

## الطابعات والمحطات

الطباعة تتم من **سيرفر الـ POS** مباشرة إلى الطابعة عبر TCP (منفذ `9100` عادةً). أجهزة الـ iPad لا تطبع بنفسها.

### إعداد مرة واحدة
1. أعطِ كل طابعة XPrinter **IP ثابت** من الراوتر (DHCP reservation).
2. من الإدارة ← **الطابعات**: أضف طابعات المطبخ وطابعات الفاتورة (العنوان + المنفذ).
3. استخدم **اختبار طباعة** للتأكد أن السيرفر يصل للطابعة.
4. من **الأصناف**: اربط كل صنف بطابعة المطبخ المناسبة.
5. أنشئ **محطات الكاشير** واربط كل محطة بطابعة فاتورة.
6. على شاشة الكاشير: اختر المحطة قبل التحصيل أو البيع السريع.

### عند فشل الطباعة (للموظفين)
1. هل الطابعة تعمل وفيها ورق؟
2. هل الـ iPad يفتح نظام الـ POS؟
3. أعد تشغيل الطابعة → الراوتر → جهاز السيرفر.

الدفع يُسجَّل حتى لو فشلت طباعة الفاتورة — ستظهر رسالة تحذير واضحة على الشاشة.

## الجلسات والصلاحيات

- كل مستخدم له **جلسة واحدة** (مدير / سفرادجي / كاشير).
- السفرادجي والكاشير **لا يصلون** للإدارة حتى يسجّلوا الخروج.
- المدير يُوجَّه تلقائياً للوحة الإدارة ولا يدخل شاشات الـ PIN.
- الكوكيز تعمل على HTTP داخل الشبكة المحلية (بدون HTTPS).

## تهيئة جزئية (مدير فقط)

في لوحة الإدارة ← أسفل القائمة: **تهيئة المبيعات والطابعات**

يتطلب كلمة مرور المدير + كتابة `RESET`.

**يُحذف:** المبيعات، الطابعات، محطات الكاشير، الموظفون (سفرادجي/كاشير).

**يُحفظ:** الأصناف، التصنيفات، الطاولات، حساب المدير.

## التقارير

في الإدارة ← **التقارير** يمكنك عرض:
- إجمالي المبيعات ونقدي/بطاقة
- الكمية المباعة حسب **الصنف**
- الكمية المباعة حسب **المجموعة** (التصنيف) مثل الحلويات
